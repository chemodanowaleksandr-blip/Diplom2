# Дипломный проект. Часть 2: Автотесты API для Stellar Burgers

Репозиторий содержит автоматизированные API-тесты для проверки учебного сервиса Stellar Burgers. Тесты написаны на Python с использованием библиотеки Requests и фреймворка PyTest.

## 🛠 Технологии и библиотеки
* **Python 3.10+** — язык программирования.
* **PyTest** — фреймворк для написания и запуска тестов.
* **Requests** — библиотека для отправки HTTP-запросов.
* **Allure-pytest** — фреймворк для генерации отчетов о тестировании.

## 📂 Структура проекта
* `data.py` — конфигурационный класс `Urls` с базовым доменом и актуальными эндпоинтами.
* `helpers.py` — вспомогательные методы (генерация уникальных данных пользователя).
* `conftest.py` — pytest-фикстура `created_user` для автоматического создания и удаления тестового пользователя.
* `test_create_user.py` — тесты логики создания и регистрации пользователей.
* `test_login_user.py` — тесты авторизации пользователя в системе.
* `test_create_order.py` — тесты логики создания заказов бургеров.

## 🚀 Порядок локального запуска тестов

1. **Перейдите в папку проекта:**
   ```bash
   cd qa-burger-api-develop2
   ```

2. **Установите все необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите тесты:**
   ```bash
   pytest -v --alluredir=allure-results
   ```
